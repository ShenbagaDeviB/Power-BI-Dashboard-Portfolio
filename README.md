# 📊 Power BI Dashboard Portfolio

Welcome to my **Power BI Dashboard Portfolio**! This repository showcases some data analysis projects built using Microsoft Power BI, focusing on data visualization, interactive reporting, and deriving meaningful insights from data.

## 👩‍💻 About This Portfolio

I am passionate about Data Analytics, Business Intelligence, and transforming raw data into meaningful insights. Through these projects, I explore different datasets and develop interactive dashboards to support data-driven decision-making.

## 📁 Dashboards

### 1. 🏦 Bank Data Analysis
An analysis of banking data using visualizations to explore relevant financial metrics and patterns.

### 2. 🚗 Car Data Analysis
A dashboard exploring automotive data, with visualizations to investigate vehicle-related metrics and trends.

### 3. 📱 Electronic Gadget Data Analysis
An exploration of electronic gadget data to identify product-related patterns and performance metrics.

### 4. 🏠 House Construction Analysis
A dashboard exploring house construction data and related metrics.

### 5. 🏥 Patient Health Analysis
An exploration of patient health data through visualizations and relevant health-related metrics.

### 6. 🛒 Sales Data Analysis
A dashboard exploring sales performance, trends, and business-related metrics.
